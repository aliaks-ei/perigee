# Security policy

## Supported versions

Security fixes are made on the latest version of the `main` branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, or pull request. Use GitHub's private vulnerability reporting form for this repository instead:

https://github.com/aliaks-ei/perigee/security/advisories/new

Include a clear description, reproduction steps, the affected code or URL, the likely impact, and any suggested remediation. You can expect an initial acknowledgement within seven days. Please allow a reasonable period for investigation and remediation before public disclosure.
