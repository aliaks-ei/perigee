# Guided Encounter directions

These targets explore the invitation, active beat, and final state over the
existing Saturn scene. They are review artifacts, not runtime assets.

## A — Horizon Whisper

Encounter copy extends the existing lower-left identity hierarchy. It has the
lowest visual and implementation cost, adapts cleanly to mobile, and leaves the
planet unobstructed. This is the recommended direction.

## B — Celestial Cut — selected

Copy behaves like film titles and disappears between beats. This direction was
selected for implementation. The live version keeps observations below the
hero, moves progress and transport to the lower edge, and uses Observatory
Notes only for the optional source disclosure.

## C — Observatory Notes

A slim field-note rail makes calculations and source boundaries tangible. It
has the clearest path to discovery disclosure, but risks feeling like a second
navigation system and is the least suitable resting state for mobile.

## Selection criteria

Choose the direction that best preserves:

1. an unobstructed reveal;
2. a coherent free-explore exit;
3. one-handed mobile controls;
4. semantic focus order and visible progress;
5. reduced-motion equivalence without losing context.

After selection, the runtime prototype must validate invitation, pause, next,
exit, completion, keyboard-only use, and reduced-motion cuts at desktop and
390 × 844 before R1.1 is marked complete.
